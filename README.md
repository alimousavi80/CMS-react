<h3>: En</h3>
<h4>
. a professional admin dashboard integrated with a backend service, refactored to React from my earlier vanilla JavaScript version
</h4>
<h4>
. designed as a SPA (single page application): navigation happens without reloading the page
</h4>
<h4>
. supabase is used for the database/backend
</h4>
<h4>
. tailwind css is utilized for styling
</h4>
<h4>
. as this is a sample project, everyone has full data manipulation access (CRUD operations: create, read, edit, delete) so that all features can be tested freely
</h4>
<h4>
. this project is not finished yet and I am still actively working on it, so more features will be added over time
</h4>
</br>
<h4> status : in progress </h4>
</div>

<h2 align="center">: FEATURES</h2>

<div align = "left">

<h4>
. courses management with Supabase (create, read, edit, delete) and instant UI update after each change, no page reload needed
</h4>
<h4>

</h4>
<h4>
. paginated courses table that stays tidy even with very long texts
</h4>
<h4>
. users management page
</h4>
<h4>
. light / dark theme, saved in the browser (localStorage) and applied without flashing on reload
</h4>
<h4>
. responsive layout with a mobile side menu
</h4>
<h4>
. dashboard home page with charts
</h4>
<h4>
. notifications dropdown and toast messages for the result of every action
</h4>
</div>

<h2 align="center">: TECH STACK</h2>

<div align = "left">

- [React](https://react.dev/) : building the user interface
- [React Router](https://reactrouter.com/) : SPA routing (hash router) and data loading with loaders
- [Vite](https://vite.dev/) : development server and build tool
- [Tailwind CSS](https://tailwindcss.com/) : styling, including the light / dark theme
- [Supabase](https://supabase.com/) : database / backend (REST API)
- [Recharts](https://recharts.org/) : dashboard charts
- [React Icons](https://react-icons.github.io/react-icons/) : icons
- [React Hot Toast](https://react-hot-toast.com/) : toast notifications

</div>

<div  align="right">

- React : ساخت رابط کاربری
- React Router : مسیر یابی SPA (از نوع hash) و گرفتن داده با loader
- Vite : سرور توسعه و ساخت نسخه ی نهایی
- Tailwind CSS : استایل دهی همراه با تم روشن / تیره
- Supabase : دیتا بیس / بک اند (REST API)
- Recharts : نمودار های داشبورد
- React Icons : آیکون ها
- React Hot Toast : پیام های toast
